
INTRODUCTION TO AGENTIC ARTIFICIAL INTELLIGENCE

Artificial Intelligence (AI) is a branch of computer science
that develops systems capable of performing tasks normally
associated with human intelligence.

Generative AI refers to AI models that create new content,
including text, images, audio, and computer code.

Agentic AI refers to AI systems that pursue goals through
planning, decision-making, tool usage, and actions.

Agentic AI systems can perform multi-step tasks and interact
with external tools to accomplish specific objectives.


LARGE LANGUAGE MODELS

Large Language Models (LLMs) are AI models trained on large
amounts of text data.

They can generate text, answer questions, summarize documents,
translate languages, and assist with programming tasks.

LLMs are commonly used in chatbots, virtual assistants,
educational applications, and automated workflows.


LANGCHAIN

LangChain is a framework used to build applications powered
by Large Language Models.

It provides components for prompt templates, model integration,
output parsing, retrieval, tools, and agent workflows.

LangChain simplifies the development of LLM-based applications.


LANGGRAPH

LangGraph is a framework for developing stateful workflows
and agent-based applications.

It represents workflows using nodes and edges.

Nodes perform operations, while edges define the execution flow.

Conditional edges allow workflows to select different paths
based on decisions or conditions.


RETRIEVAL-AUGMENTED GENERATION

Retrieval-Augmented Generation (RAG) is a technique that
combines information retrieval with Large Language Models.

A RAG system retrieves relevant information from external
documents before generating an answer.

RAG systems commonly use embeddings and vector databases
to perform semantic similarity searches.

The retrieved information is supplied to the LLM as context
for generating document-grounded responses.

RAG can reduce hallucinations and improve the relevance
of responses when suitable documents are available.


VECTOR DATABASES

A vector database stores numerical representations of data
called embeddings.

Embeddings capture semantic relationships between pieces
of text.

Vector databases support similarity search to retrieve
documents related to a user query.

Examples include Chroma, FAISS, and Pinecone.


CHROMADB

ChromaDB is a vector database used to store embeddings
and perform similarity-based document retrieval.

It can be integrated with LangChain to build RAG applications.

ChromaDB supports document storage, metadata, and vector
similarity search.


APPLICATIONS OF RAG

RAG is used in document question-answering systems,
educational chatbots, enterprise knowledge assistants,
research tools, and customer support applications.

It enables LLM applications to use information from
external documents instead of relying only on
the model's internal knowledge.
