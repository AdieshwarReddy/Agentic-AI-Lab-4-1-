# Experiment 1: Rule-Based Intelligent Agent

## Aim
To design and implement a simple rule-based intelligent agent for task scheduling and demonstrate goal-oriented decision-making.

## Objective
To understand how an intelligent agent uses predefined rules to prioritize and schedule tasks.

## Theory
A rule-based intelligent agent is an AI system that makes decisions using predefined IF-THEN rules.

In this experiment, tasks are scheduled based on their priority and deadline.

Rules:
- Priority 1 represents high priority.
- Priority 2 represents medium priority.
- Priority 3 represents low priority.
- Tasks with equal priority are ordered by deadline.

## Algorithm
1. Start the program.
2. Define tasks with priorities and deadlines.
3. Apply rule-based scheduling.
4. Sort tasks by priority and deadline.
5. Display the scheduled tasks.
6. Stop the program.

## Technologies Used
- Python 3
- Rule-Based Decision Making

## How to Run
```bash
python main.py
```

## Result
A rule-based intelligent agent was implemented to schedule tasks according to their priority and deadline.

## Conclusion
This experiment demonstrates how predefined rules can be used by an intelligent agent to make scheduling decisions.
