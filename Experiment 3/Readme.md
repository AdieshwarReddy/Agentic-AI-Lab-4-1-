
# Experiment 3: Prompt Engineering Using LLMs

## Aim

To experiment with zero-shot, few-shot, and chain-of-thought prompting using a Large Language Model (LLM) and compare the generated outputs.

## Objective

To understand different prompt engineering techniques and analyze how prompt structure influences the responses generated by Large Language Models.

## Theory

### What is Prompt Engineering?

Prompt engineering is the process of designing effective instructions for Large Language Models to obtain accurate, relevant, and meaningful responses.

### 1. Zero-Shot Prompting

Zero-shot prompting involves asking an LLM to perform a task without providing examples.

Example:

Prompt:
"Classify the sentiment of this sentence: I love learning Artificial Intelligence."

Expected Response:
"Positive"

### 2. Few-Shot Prompting

Few-shot prompting involves providing examples to help the model understand the expected input-output format.

Example:

Prompt:
"Classify the sentiment of the following sentences:

I love Python. -> Positive
This application is terrible. -> Negative
The weather is normal. -> Neutral
AI makes learning interesting. ->"

Expected Response:
"Positive"

### 3. Chain-of-Thought Prompting

Chain-of-thought prompting encourages an LLM to break down a complex problem into intermediate reasoning steps.

Example:

Prompt:
"A student has 5 books and buys 3 more books. Each book costs Rs. 100. Calculate the total value of the books. Show the calculation steps."

Expected Response:

Initial books = 5
Additional books = 3
Total books = 8
Cost per book = Rs. 100
Total value = Rs. 800

## Comparison of Prompting Techniques

| Technique | Description | Examples Provided |
|-----------|-------------|-------------------|
| Zero-Shot | Direct instruction | No |
| Few-Shot | Instruction with examples | Yes |
| Chain-of-Thought | Requests intermediate reasoning steps | Optional |

## Algorithm

1. Start the program.
2. Initialize the Large Language Model.
3. Define a zero-shot prompt.
4. Send the prompt to the LLM and display the response.
5. Define a few-shot prompt with examples.
6. Send the prompt and display the response.
7. Define a chain-of-thought prompt.
8. Generate and display the calculation steps.
9. Compare the three responses.
10. Stop the program.

This experiment demonstrates how different prompting techniques influence LLM responses.
