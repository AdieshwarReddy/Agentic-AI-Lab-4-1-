
# Experiment 2: Traditional AI vs Generative AI vs Agentic AI
 
## Aim
To compare Traditional AI, Generative AI, and Agentic AI by implementing simple Python-based examples.

## Objective
To understand the differences between Traditional AI, Generative AI, and Agentic AI through practical demonstrations.

## Theory

### 1. Traditional AI
Traditional AI focuses on analyzing information, recognizing patterns, and making decisions based on predefined rules or trained models.

Example: A rule-based system that predicts whether a student passes or fails based on marks.

### 2. Generative AI
Generative AI creates new content such as text, images, audio, or code based on learned patterns.

Example: A text-generation model that creates a motivational message.

### 3. Agentic AI
Agentic AI refers to AI systems that pursue goals by planning, making decisions, and taking actions, often using tools and feedback.

Example: An agent that evaluates tasks and selects the next task based on priority.

## Comparison

| Feature | Traditional AI | Generative AI | Agentic AI |
|---------|----------------|---------------|------------|
| Purpose | Prediction and classification | Content generation | Goal-oriented action |
| Output | Decisions or predictions | Text, images, code | Actions and task results |
| Autonomy | Usually limited | Usually prompt-driven | Can execute multi-step workflows |
| Example | Pass/fail classifier | Text generator | Task planning agent |

## Algorithm

1. Start the program.
2. Implement a rule-based classifier as a Traditional AI example.
3. Implement a simple text-generation model as a Generative AI example.
4. Implement a goal-oriented task-selection agent as an Agentic AI example.
5. Display the results of all three approaches.
6. Compare their functionality.
7. Stop the program.

## Technologies Used

- Python 3
- Rule-Based Systems
- Markov Chain Text Generation
- Goal-Oriented Agents

## How to Run

```bash
python main.py
```

## Expected Result

The program demonstrates:
- Traditional AI through pass/fail classification.
- Generative AI through simple text generation. 
- Agentic AI through task selection and execution.

## Conclusion

This experiment demonstrates the differences between Traditional AI, Generative AI, and Agentic AI using simple Python implementations.

Traditional AI makes predictions or decisions, Generative AI creates content, and Agentic AI focuses on achieving goals through decisions and actions.
